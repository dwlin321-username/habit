# 要拚要猛 🔥

一個幫你打敗拖延、每天完成待辦事項的 iPhone 主畫面小工具。
完成任務就能孵出 3D 可愛動物，收集進圖鑑！

## 怎麼放到 iPhone 主畫面

1. 用 **Safari** 打開網址（例如 `https://你的帳號.github.io/yao-pin-yao-meng/`）
2. 點下方的「分享」按鈕 → 選「加入主畫面」
3. 之後都從主畫面的圖示打開

> ⚠️ 一定要從主畫面打開使用。只在 Safari 裡用的話，7 天沒打開，資料可能被 iOS 清掉。
> ⚠️ 刪除主畫面圖示時，資料會一起刪除，記得先到「設定 → 備份資料」。

## 每天怎麼用

1. **每天第一次打開**：看看昨天沒完成的任務（繼續／拆得更小／放回清單／刪除）
2. **選今天要做的事**：從清單勾選，數量不限
3. **決定何時、在哪裡做**：時間必填、地點選填
4. **按「🚀 開始」**：畫面只顯示「2 分鐘起步動作」，先做這一小步就好
5. **按「✅ 完成」**：孵蛋得到 3D 動物，當天第一件完成還會得到月曆貼紙

## 獎勵規則

| 任務難度 | 得到的動物 |
|---|---|
| ★ 輕鬆 | 普通（15% 機率變稀有） |
| ★★ 普通 | 稀有（15% 機率變史詩） |
| ★★★ 超難 | 史詩，並累積傳說進度 |

- 每累計完成 5 件 ★★★ 任務 → 解鎖一隻還沒擁有的**傳說**動物
- 抽到重複的 → 變成碎片：普通 1、稀有 3、史詩 9
- 3 碎片換稀有蛋、9 碎片換史詩蛋（會優先孵出還沒擁有的）
- 圖鑑共 44 隻：普通 18、稀有 12、史詩 8、傳說 6

## 檔案結構

```
index.html          主頁面
css/style.css       樣式（馬卡龍粉彩風、支援深色模式）
js/app.js           畫面與操作
js/data.js          資料存檔、抽獎規則、圖鑑清單
js/stage3d.js       3D 動物顯示
sw.js               Service Worker（讓 App 可離線使用、自動更新）
manifest.json       App 名稱、圖示設定
models/             3D 動物模型（.glb）
vendor/three/       three.js 3D 引擎
icons/              主畫面圖示
```

## 更新 App

修改程式後，把 `sw.js` 最上面的 `VERSION` 改成新的版本號（例如 `v1.0.1`）。
iPhone 下次打開時會出現「有新版本可以更新」的提示。
